    Поки активне вікно голодування — будь-які калорії розривають піст. Що саме вважати «розривом» залежить від цілі: для зниження ваги м'якше, для аутофагії суворіше.

    ✅ Можна — не розриває піст
    • Звичайна вода — необмежено
    • Газована/мінеральна вода без ароматизаторів і солодіння
    • Чорна кава 1–3 чашки (~2 ккал/чашка). Без молока, цукру, вершків
    • Чай зелений/чорний/трав'яний — без додавань
    • Електроліти без калорій — сіль, магній, калій (без цукру/підсолоджувачів). Особливо при довгих постах щоб не паморочилось
    ⚠️ Спірно — залежить від цілі
    • Стевія у каві/чаї — для схуднення ОК, інсулін не стрибає. Для аутофагії ⚠️ — деякі джерела радять уникати
    • Аспартам, сукралоза, ace-K — нуль калорій, але можуть стимулювати інсулін через смакові рецептори. Краще уникати для строгого посту
    • Яблучний оцет 1–2 ч.л. — мінімум калорій, зазвичай ОК
    • Кофеїн сам по собі знижує чутливість до інсуліну на ~15% коротко. Для weight loss — не проблема, для insulin-focused — обмежити
    • Дієтична кола / «zero» напої — те саме що штучні підсолоджувачі
    ❌ Не можна — розриває піст
    • Молоко, вершки, рослинне молоко у каві — навіть ложечка
    • Цукор, мед, сиропи — будь-яка кількість
    • Соки, газовані з цукром, фруктові води
    • Кістковий бульйон — калорії + білок → інсулін
    • BCAA / амінокислотні добавки — амінокислоти запускають інсулін
    • Bulletproof / MCT кава — калорії з жиру, технічно розриває піст
    • Протеїнові коктейлі, смузі
    • Жуйки з цукром (без цукру — спірно)
    • Будь-які перекуси — горіхи, фрукти, навіть «трошки»
    🎯 За цілями — наскільки строго
    • Схуднення / метаболіка → дозволено: вода, чорна кава, чай, електроліти. Стевію + підсолоджувачі — ОК у міру
    • Аутофагія → строго: тільки вода + електроліти + декофеїнізований трав'яний чай. Жодних амінокислот, підсолоджувачів
    • Чутливість до інсуліну → уникати навіть нульо-калорійних солодких смаків

    Не медична порада. Якщо є діабет, вагітність, розлади харчової поведінки — консультація з лікарем перед IF.

    Як це працює технічно — дані, синхронізація, бот, приватність.

    🔐 Дані та приватність

    Де зберігається моя історія?
    У Telegram CloudStorage — безкоштовному хмарному сховищі Telegram, до 1024 записів на користувача. Дані прив'язані до твого Telegram-аккаунта.

    Якщо відкриваєш app поза Telegram (з браузера) — fallback на localStorage браузера, тільки локально на цьому пристрої.
    Хто бачить мої дані?
    Тільки ти. CloudStorage шифрує дані на стороні Telegram; розробник app не має до них доступу. Сервери Telegram бачать тільки encrypted blob'и під твоїм Telegram ID.
    Чи синхронізуються дані між моїми пристроями?
    Так, автоматично. Відкрий app на телефоні + у Telegram Desktop → побачиш той самий поточний таймер і ту саму історію. Sync — частина CloudStorage.
    Що буде якщо очистити кеш Telegram чи переустановити?
    Історія залишиться. CloudStorage живе на серверах Telegram, не локально. При наступному вході — підвантажиться знову.
    Як видалити всі мої дані?
    Кнопки "видалити все" ще нема (TODO). Зараз можна вручну: написати @BotFather → /deletewebappdata — очистить CloudStorage для цього app. Або з браузера: відкрити URL → DevTools → Application → Local Storage → Clear.

    🔔 Бот та нагадування

    Звідки приходять push-нагадування?
    Окремий компонент — Telegram бот @fasting_tracker_ua_bot. Він живе у Docker контейнері на окремому хості, використовує Telegram Bot API через long-polling, зберігає таймери у SQLite.
    Бот бачить мою історію з Mini App?
    Бот бачить тільки поточний активний таймер (старт + протокол) — щоб знати коли надсилати нагадування. Повна історія голодувань залишається тільки у твоєму CloudStorage. Бот не зберігає і не бачить минулі сесії.
    Як Mini App "розповідає" боту про старт?
    Коли тиснеш 16:8 у Mini App, він POST'ить запит на HTTPS endpoint бота (через Cloudflare Tunnel) з твоїм підписаним initData. Бот валідує підпис через HMAC-SHA256 (стандарт Telegram), дістає user_id, і планує нагадування. Якщо бот недоступний — Mini App продовжує працювати локально (таймер + історія), але без нагадувань. У такому випадку зверху таймера зʼявляється «⚠️ Бот недоступний».

    🛠 Стек і код

    Який стек?
    Mini App: vanilla HTML + JavaScript + CSS. Нуль dependencies, нуль build step. ~640 рядків коду.

    Bot: Python 3.12, aiogram 3, SQLite, APScheduler. Docker з restart: always.

    Hosting: Mini App — GitHub Pages (статика). Bot — Docker контейнер на окремому хості (long-polling, не webhook).
    Open source? Можна fork'нути?
    Repo приватний на github.com/rossanoua/fasting-app. Якщо хочеш forka — пиши власнику.
    Як працює таймер коли app закритий?
    Mini App нічого не робить коли закритий — це звичайна веб-сторінка. Зберігається timestamp старту. При наступному відкритті: elapsed = now - start. Тому таймер завжди точний — навіть якщо app не відкривати тиждень.

    Напомінання приходять незалежно від того чи відкритий app — їх шле бот зі свого розкладу.
    Чи треба інтернет?
    Для першого завантаження сторінки — так. Після — Telegram кешує WebApp файли. Активний таймер працює offline (timestamp у CloudStorage). Sync між пристроями — при першому online connection.
