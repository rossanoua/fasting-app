    Поки активне вікно голодування — будь-які калорії розривають піст. Що саме вважати «розривом» залежить від цілі: для зниження ваги м'якше, для аутофагії суворіше.

    ✅ Можна — не розриває піст
    • Звичайна вода — необмежено
    • Газована/мінеральна вода без ароматизаторів і солодіння
    • Чорна кава 1–3 чашки (~2 ккал/чашка). Без молока, цукру, вершків
    • Чай зелений/чорний/трав'яний — без додавань
    • Електроліти без калорій — сіль, магній, калій (без цукру/підсолоджувачів). Особливо при довгих постах щоб не паморочилось
    ⚠️ Спірно — залежить від цілі
    • Стевія у каві/чаї — для схуднення ОК, інсулін не стрибає. Для аутофагії ⚠️ — деякі джерела радять уникати
    • Аспартам, сукралоза, ace-K — нуль калорій, але можуть стимулювати інсулін через смакові рецептори. Краще уникати для строгого посту
    • Яблучний оцет 1–2 ч.л. — мінімум калорій, зазвичай ОК
    • Кофеїн сам по собі знижує чутливість до інсуліну на ~15% коротко. Для weight loss — не проблема, для insulin-focused — обмежити
    • Дієтична кола / «zero» напої — те саме що штучні підсолоджувачі
    ❌ Не можна — розриває піст
    • Молоко, вершки, рослинне молоко у каві — навіть ложечка
    • Цукор, мед, сиропи — будь-яка кількість
    • Соки, газовані з цукром, фруктові води
    • Кістковий бульйон — калорії + білок → інсулін
    • BCAA / амінокислотні добавки — амінокислоти запускають інсулін
    • Bulletproof / MCT кава — калорії з жиру, технічно розриває піст
    • Протеїнові коктейлі, смузі
    • Жуйки з цукром (без цукру — спірно)
    • Будь-які перекуси — горіхи, фрукти, навіть «трошки»
    🎯 За цілями — наскільки строго
    • Схуднення / метаболіка → дозволено: вода, чорна кава, чай, електроліти. Стевію + підсолоджувачі — ОК у міру
    • Аутофагія → строго: тільки вода + електроліти + декофеїнізований трав'яний чай. Жодних амінокислот, підсолоджувачів
    • Чутливість до інсуліну → уникати навіть нульо-калорійних солодких смаків

    Не медична порада. Якщо є діабет, вагітність, розлади харчової поведінки — консультація з лікарем перед IF.
